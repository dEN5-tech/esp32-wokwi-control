# 💡 ПРАКТИЧЕСКАЯ РАБОТА: Управление микроконтроллером ESP32 по протоколу TCP через JavaFX

**Дисциплина / Модуль:** Разработка клиент-серверных IoT-приложений (JavaFX + ESP32)  
**Инструменты:** VSCodium / VS Code, Scene Builder, Wokwi Simulator, JavaFX SDK 17+.

---

## 1. Цель работы

1. Изучить принцип прямого сетевого взаимодействия клиента и микроконтроллера по протоколу **TCP (Socket)**.
2. Спроектировать графический интерфейс управления в визуальном редакторе **Scene Builder** (`MainView.fxml`).
3. Привязать компоненты интерфейса (`fx:id` и `On Action`) к классу-контроллеру `MainController.java`.
4. Реализовать логику отправки команд (`ON`, `OFF`, `STATUS`) на ESP32 с использованием готового метода `sendTcp()`.
5. Протестировать работу системы в связке с виртуальной платой в симуляторе **Wokwi**.

---

## 2. Архитектура и протокол взаимодействия по TCP

Микроконтроллер ESP32 поднимает TCP-сервер на порту **8080**. Симулятор Wokwi пробрасывает этот порт на ваш локальный компьютер (`127.0.0.1:8080`).

| Команда (Client $\rightarrow$ ESP32) | Описание действия | Ответ сервера (ESP32 $\rightarrow$ Client) | Действие на плате |
| :--- | :--- | :--- | :--- |
| **`STATUS`** | Запрос текущего состояния | `STATUS: ON` или `STATUS: OFF` | Без изменений |
| **`ON`** | Включение нагрузки | `OK: LED turned ON` | Зажигает светодиод (GPIO 23) |
| **`OFF`** | Выключение нагрузки | `OK: LED turned OFF` | Гасит светодиод (GPIO 23) |

---

## 3. Схема устройства в Wokwi (`esp32-tcp-wokwi/diagram.json`)

* **Плата:** ESP32 DevKit v4
* **Нагрузка:** Светодиод (LED) подключен к пину **GPIO 23** через токоограничивающий резистор 220 Ом к пину `GND`.

## 5. Задание 2: Реализация логики в `MainController.java`

Откройте файл `javafx-client/src/com/example/MainController.java`.

### Шаг 1. Объявите переменные интерфейса:
```java
@FXML private TextField ipInput;
@FXML private TextField portInput;
@FXML private Label statusLabel;
@FXML private Label ledStatusLabel;
@FXML private TextArea logArea;
```

---

### Шаг 2. Реализуйте методы-обработчики кнопок:

Используйте готовый метод `sendTcp(ip, port, command)`, который отправляет команду микроконтроллеру и возвращает ответ в виде строки:

```java
@FXML
void handleConnect() {
    String ip = ipInput.getText().trim();
    int port = Integer.parseInt(portInput.getText().trim());

    // Отправляем команду проверки статуса
    String response = sendTcp(ip, port, "STATUS");

    if (response != null) {
        statusLabel.setText("Статус: Подключено к ESP32");
        logArea.appendText("Соединение успешно! Ответ: " + response + "\n");
    } else {
        statusLabel.setText("Статус: Ошибка подключения");
        logArea.appendText("Не удалось связаться с сервером.\n");
    }
}

@FXML
void handleTurnOn() {
    String ip = ipInput.getText().trim();
    int port = Integer.parseInt(portInput.getText().trim());

    // Отправляем команду включения
    String response = sendTcp(ip, port, "ON");

    if (response != null) {
        ledStatusLabel.setText("Состояние светодиода: ВКЛ");
        logArea.appendText("Ответ: " + response + "\n");
    }
}

@FXML
void handleTurnOff() {
    String ip = ipInput.getText().trim();
    int port = Integer.parseInt(portInput.getText().trim());

    // Отправляем команду выключения
    String response = sendTcp(ip, port, "OFF");

    if (response != null) {
        ledStatusLabel.setText("Состояние светодиода: ВЫКЛ");
        logArea.appendText("Ответ: " + response + "\n");
    }
}

@FXML
void handleGetStatus() {
    String ip = ipInput.getText().trim();
    int port = Integer.parseInt(portInput.getText().trim());

    String response = sendTcp(ip, port, "STATUS");

    if (response != null) {
        logArea.appendText("Статус устройства: " + response + "\n");
        if (response.contains("ON")) {
            ledStatusLabel.setText("Состояние светодиода: ВКЛ");
        } else {
            ledStatusLabel.setText("Состояние светодиода: ВЫКЛ");
        }
    }
}
```

## 6. Порядок сборки, запуска и тестирования

1. **Запуск симулятора Wokwi:**
   * Откройте папку `esp32-tcp-wokwi` и файл `diagram.json`.
   * Нажмите **F1** $\rightarrow$ **`Wokwi: Start Simulator`** (или зелёную кнопку Play ▶️).
   * В логах симулятора появится сообщение: `TCP Server listening on port: 8080`.

2. **Запуск клиентского приложения JavaFX:**
   * Нажмите **`F5`** в VSCodium (или запустите `javafx-client/run.bat`).

3. **Проверка работы:**
   * Нажмите **«Проверить связь»** $\rightarrow$ убедитесь, что статус изменился на «Подключено».
   * Нажмите кнопку **«ВКЛ (ON)»** $\rightarrow$ светодиод в симуляторе Wokwi загорится красным.
   * Нажмите кнопку **«ВЫКЛ (OFF)»** $\rightarrow$ светодиод в симуляторе Wokwi погаснет.
   * Проверьте вывод ответов сервера в окне логов `logArea`.
