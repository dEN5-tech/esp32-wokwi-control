# 💡 ПРАКТИЧЕСКАЯ РАБОТА: Управление Arduino Uno через Scene Builder и JavaFX

**Инструменты:** VSCodium / VS Code, Scene Builder, Wokwi Simulator, JavaFX SDK.

---

## 1. Задача
Создать простой интерфейс в Scene Builder с 3 кнопками (**ВКЛ**, **ВЫКЛ**, **Статус**) и связать их с платой Arduino Uno в симуляторе Wokwi.

---

## 2. Команды для Arduino (порт 4001)

| Команда | Описание | Ответ платы |
| :--- | :--- | :--- |
| **`ON`** | Зажечь светодиод на пине 13 | `OK: LED turned ON` |
| **`OFF`** | Погасить светодиод на пине 13 | `OK: LED turned OFF` |
| **`STATUS`** | Узнать текущее состояние | `STATUS: ON` или `STATUS: OFF` |

---

## 3. Шаг 1: Интерфейс в Scene Builder (`MainView.fxml`)

Откройте `MainView.fxml` в Scene Builder (правый клик $\rightarrow$ **Open with SceneBuilder**).

### Дерево элементов (Hierarchy):
```text
▼ VBox (spacing="12", alignment="CENTER", padding="15")
    ├── Label (Text: "Управление Arduino Uno")
    ▼ HBox (spacing="8", alignment="CENTER")
    │   ├── Label (Text: "IP:")
    │   ├── TextField (fx:id="ipField", text="127.0.0.1")
    │   ├── Label (Text: "Порт:")
    │   └── TextField (fx:id="portField", text="4001")
    ▼ HBox (spacing="10", alignment="CENTER")
    │   ├── Button (Text: "ВКЛ (ON)", On Action="#onTurnOn")
    │   ├── Button (Text: "ВЫКЛ (OFF)", On Action="#onTurnOff")
    │   └── Button (Text: "Статус", On Action="#onCheckStatus")
    ├── Label (fx:id="statusLabel", text="Состояние: Неизвестно")
    └── TextArea (fx:id="logArea", editable="false")
```

### Таблица привязки компонентов:

## 4. Шаг 2: Логика в `MainController.java`

Откройте `MainController.java` и допишите обработчики кнопок, используя готовый метод `sendSerial(команда)`:

```java
@FXML
void onTurnOn() {
    String reply = sendSerial("ON");
    if (reply != null) {
        statusLabel.setText("Светодиод: ВКЛ");
        logArea.appendText("Arduino: " + reply + "\n");
    }
}

@FXML
void onTurnOff() {
    String reply = sendSerial("OFF");
    if (reply != null) {
        statusLabel.setText("Светодиод: ВЫКЛ");
        logArea.appendText("Arduino: " + reply + "\n");
    }
}

@FXML
void onCheckStatus() {
    String reply = sendSerial("STATUS");
    if (reply != null) {
        if (reply.contains("ON")) {
            statusLabel.setText("Светодиод: ВКЛ");
        } else {
            statusLabel.setText("Светодиод: ВЫКЛ");
        }
        logArea.appendText("Статус: " + reply + "\n");
    }
}
```

---

## 5. Запуск и проверка

1. В папке `arduino-uno-wokwi` откройте `diagram.json` и нажмите **Play ▶️**.
2. В редакторе нажмите **`F5`** (или запустите `javafx-client/run.bat`).
3. Нажмите **ВКЛ (ON)** — светодиод в симуляторе загорится.
4. Нажмите **ВЫКЛ (OFF)** — светодиод в симуляторе погаснет.
