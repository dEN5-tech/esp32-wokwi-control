# 💡 ПРАКТИЧЕСКАЯ РАБОТА: Управление сервоприводом Arduino Uno через JavaFX (Scene Builder)

**Инструменты:** VSCodium / VS Code, Scene Builder, Wokwi Simulator, JavaFX SDK.

---

## 1. Задача
Разработать графический интерфейс управления сервоприводом с ползунком (Slider от 0° до 180°), быстрыми кнопками (0°, 90°, 180°) и связать его с виртуальной платой Arduino Uno в Wokwi.

---

## 2. Команды протокола Serial (порт 4002)

| Команда | Описание | Ответ платы |
| :--- | :--- | :--- |
| **`ANGLE <угол>`** | Установить угол от 0 до 180 градусов (например, `ANGLE 90`) | `OK: <угол>` |
| **`STATUS`** | Запрос текущего положения вала | `ANGLE: <угол>` |

---

## 3. Схема в Wokwi (`arduino-uno-wokwi/diagram.json`)

* **Плата:** Arduino Uno
* **Сервопривод:** Пин `PWM` подключен к пину **9**, `V+` к **5V**, `GND` к **GND**.

## 5. Шаг 2: Логика в `MainController.java`

Откройте `MainController.java` и допишите обработчики кнопок:

```java
@FXML
void onApplyAngle() {
    int angle = (int) angleSlider.getValue();
    String reply = sendSerial("ANGLE " + angle);
    if (reply != null) {
        statusLabel.setText("Текущий угол: " + angle + "°");
        logArea.appendText("Arduino: " + reply + "\n");
    }
}

@FXML
void onSet0() {
    angleSlider.setValue(0);
    onApplyAngle();
}

@FXML
void onSet90() {
    angleSlider.setValue(90);
    onApplyAngle();
}

@FXML
void onSet180() {
    angleSlider.setValue(180);
    onApplyAngle();
}

@FXML
void onGetStatus() {
    String reply = sendSerial("STATUS");
    if (reply != null) {
        statusLabel.setText("Текущее положение: " + reply);
        logArea.appendText("Статус: " + reply + "\n");
    }
}
```

---

## 6. Запуск и проверка

1. В папке `arduino-uno-wokwi` откройте `diagram.json` и нажмите **Play ▶️**.
2. В редакторе нажмите **`F5`** (или запустите `javafx-client/run.bat`).
3. Двигайте ползунок или нажимайте кнопки пресетов `0°`, `90°`, `180°` — лопасть сервопривода в симуляторе будет поворачиваться на соответствующий угол.
